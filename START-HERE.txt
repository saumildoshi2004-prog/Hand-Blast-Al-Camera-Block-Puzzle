HAND BLAST — FINAL CAMERA FIX

Your Chrome address is now correct:
http://localhost:5500

The previous problem was that the Enable Camera button depended on the
MediaPipe module loading first. If MediaPipe failed, the button had no
click handler. This version fixes that.

RUN:
1. Extract this ZIP.
2. Open the block-blast-camera-complete folder.
3. Double-click START-GAME.bat.
4. Open http://localhost:5500.
5. Click ENABLE CAMERA.
6. Chrome should immediately ask for camera permission.
7. Click Allow.
8. You should enter the game even before hand tracking finishes.

If Chrome still does not show a permission popup:
- Click the icon at the left of localhost:5500 in the address bar.
- Open Site settings.
- Camera -> Allow.
- Reload the page.
- Click ENABLE CAMERA again.

The game uses the MediaPipe CDN for hand tracking, so internet is required.
